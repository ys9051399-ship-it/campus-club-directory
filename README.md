# Campus Club Directory

A responsive web application designed to help students explore and discover
campus clubs in one place.

## 📌 About the Project

Campus Club Directory provides detailed information about different campus
clubs, allowing students to easily explore clubs based on their interests,
activities, and categories.

The goal of this project is to make it easier for students to discover
opportunities outside academics and get involved in campus activities.

## ✨ Features

- Browse different campus clubs
- Detailed information about each club
- Club categories and activities
- Easy-to-use navigation
- Responsive design
- Student-friendly interface
- Clean and modern UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

1. Clone the repository
2. Open the project folder
3. Open `index.html` in your browser
